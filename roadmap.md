# OnPagePro — Build Roadmap

Focused build from the approved plan: multi-website on-page SEO tool for **meta title, meta description, headings**.

- [ ] 1. Enable Lovable Cloud + email auth; migration (schema, RLS, grants)
- [ ] 2. Auth gate + app shell (sidebar, website switcher, theme) + website CRUD
- [ ] 3. Page import: URL / sitemap.xml / CSV / limited crawl (SSRF guards)
- [ ] 4. Analyzer: title, description, headings, keywords + weighted score + findings
- [ ] 5. Pages table with filters + page editor (tabs, snippet preview, drafts, history)
- [ ] 6. AI assistant in editor (Lovable AI Gateway)
- [ ] 7. CSV export (audit + recommendations)
- [ ] 8. Verify: analyzer tests + Playwright end-to-end, desktop + mobile
